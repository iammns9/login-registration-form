# Login & Registration Form

A clean, modern login and sign-up page built with vanilla HTML, CSS, and JavaScript.
---

## Features

- Sign In & Sign Up toggle (single page, no reload)
- Form validation with shake animation on errors
- Password show/hide toggle
- Forgot Password model with email check
- Social login buttons (Google, Facebook, Twitter, GitHub)
- Animated network canvas background
- Animated floating illustration (video)
- Fully responsive (mobile, tablet, desktop)
- Glassmorphism card design with white theme

---

## Built With

- HTML5
- CSS3 (Glassmorphism, Animations, Flexbox)
- Vanilla JavaScript (ES6+)
- [Boxicons](https://boxicons.com/) — icons
- [DM Sans](https://fonts.google.com/specimen/DM+Sans) — font (Google Fonts)
- Canvas API — animated network background

##  Getting Started

1. Clone the repo
```bash
git clone https://github.com/iammns9/login-registration-form.git
```

2. Open `templates/html/login.html` in your browser — no build tools needed.

>  Social login and forgot password email are **mock/frontend only**.
> Wire up a real backend (e.g. Firebase, Node.js) for production use.
